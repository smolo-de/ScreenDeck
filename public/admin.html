Screens

Menü beim Antippen

Name/ID, Vollbild, Ton, Fernsteuerung, Neu laden. Ausgeschaltet schaltet Antippen nur in den Vollbildmodus, z. B. für öffentlich zugängliche Touch-Screens.

Zoomen per Fingergeste

Bilder und Texte lassen sich vergrößern und verschieben. Solange vergrößert ist, hält der Screen den Inhalt an. Nach 60 s ohne Berührung oder beim nächsten Inhalt geht es normal weiter.

Smartphone als Fernbedienung

Per QR-Code gekoppelte Geräte dürfen sofort fernsteuern und Fotos, Videos und Musik hochladen – ohne Freischaltung in der Screen-Liste. „Neuer Code“ macht den bisherigen ungültig; bereits gekoppelte Geräte behalten ihre Freigabe (in der Screen-Liste sperrbar).

Name im Netzwerk

http:// .local:3000

Geräte im selben Netzwerk erreichen den Server unter diesem Namen statt über die IP-Adresse. Das klappt mit Windows, macOS, iPhone/iPad und neueren Android-Geräten. Manche ältere Android-Fernseher kennen solche Namen nicht, dort die IP-Adresse verwenden. Leer = aus.

Ports

Zusätzlicher Port

80 = Adressen ganz ohne Portangabe. Ist Port 80 belegt oder nicht erlaubt, einen anderen freien Port wählen (z. B. 8080). 0 = aus. Wirkt sofort.

Hauptport

Unter diesem Port ist der Server immer erreichbar (Standard 3000). Änderung wirkt nach einem Neustart des Servers.

Bildqualität für Screens

Vorgabe für alle Screens

Pro Screen abweichend einstellbar (in der Screen-Liste oder im Menü am Screen).

Zwischenspeicher

Belegt: …

Verkleinert und komprimiert Bilder, bevor sie an die Screens gehen – spart Ladezeit und Datenmenge (z. B. Fotos vom Netzlaufwerk oder WLAN-Tablets). Die Fassung wird beim ersten Abruf erzeugt und zwischengespeichert, die Originaldateien bleiben unverändert. Videos, GIFs und SVGs werden nicht verändert.

Medienquellen

Ordner, deren Bilder und Videos unter „Medien“ erscheinen: lokale Ordner, Netzlaufwerke (z. B. Z:\Videos) oder Netzwerkpfade (z. B. \\NAS\Freigabe\Videos). Abgespielt wird direkt von dort, nichts wird kopiert.

🔑 Anmeldung (optional)

Netzwerk: oben \\Servername (z. B. \\sugo) eingeben und „Durchsuchen“ – dann erscheinen die Freigaben. Braucht der Server eine Anmeldung, vorher Benutzer und Kennwort angeben.

Netzlaufwerke müssen für das Benutzerkonto erreichbar sein, unter dem der Server läuft. Läuft der Server als Dienst oder „als Administrator“, sind verbundene Laufwerksbuchstaben oft nicht sichtbar – dann den Netzwerkpfad (\\Server\Freigabe) verwenden.

Braucht die Freigabe eine Anmeldung, Benutzer und Kennwort angeben (bei bestehenden Quellen über 🔑). Der Server meldet sich damit an, das Kennwort wird verschlüsselt mit dem Windows-Konto des Servers gespeichert und nie angezeigt. Windows erlaubt je Server nur eine Anmeldung: Alle Freigaben desselben Servers nutzen denselben Benutzer.

Zugriffsschutz

Standardmäßig ist nichts geschützt. Mit einer PIN fragt die Seite einmal danach, das Gerät bleibt danach angemeldet. Eine leere PIN bzw. „Entfernen“ hebt den Schutz wieder auf.

Verwaltung

PIN gut notieren! Wer sie nicht kennt, kommt nicht mehr in die Verwaltung. Notfalls in data/state.json den Eintrag "admin" unter "auth" löschen und den Server neu starten.

Screens

Bereits verbundene Screens bleiben angemeldet. Neue Geräte fragen einmal nach der PIN. Für Kiosk-Geräte geht es auch direkt über die Adresse: /screen?pin=123456.
